使用说明

URL 格式：

mod://<modid>/<filename.html>

资源文件需要放在 Mod 的 assets/<modid>/html/ 目录下。

例如：本页面文件位于 assets/rinku/html/index.html， 通过 mod://rinku/index.html 访问。
